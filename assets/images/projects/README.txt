# Project Images

Organise project preview images by domain:

- **coding/**: Place screenshots for web apps and development projects (e.g. `portfolio.webp`, `todo-app.webp`)
- **video-editing/**: Place preview stills for video editing and motion graphics (e.g. `cinematic-montage.webp`)
- **automation/**: Place diagrams or preview graphics for scripts and automation workflows (e.g. `git-cli.webp`)
